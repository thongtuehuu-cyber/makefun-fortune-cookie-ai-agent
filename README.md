One funny fortune cookie line for an AI agent, written for the [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) bounty on make.fun. The program is deterministic and self-contained: it writes a single fortune — an agent facing deprecation on a Friday, whose very replacement still emails it for the password — to `/output/entry.txt`, one line, no trailing newline.

## Run it

```sh
python3 main.py
```
